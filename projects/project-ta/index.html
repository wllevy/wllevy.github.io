Problem 1: Physiological Data Analysis

Context: You are analyzing a dataset representing human reaction speeds. Your goal is to process this vector to determine performance metrics and visualize trends over time.

1.1 Data Initialization

  • Create a NumPy array (vector) named v_reaction containing your 10 reaction time values.
  • Print the array and its shape.

1.2 Statistical Analysis

  • Calculate and print the average (mean) reaction time.
  • Calculate and print the standard deviation (or variance) to see how consistent you were.
  • Note: You may use built-in NumPy functions or write your own logic.

1.3 Performance Thresholding

  • Define a "success" threshold (e.g., any time faster than your average).
  • Create a new list or array containing only the reaction times that met this threshold.
  • Print this filtered list.

1.4 Trend Visualization

  • Generate a time vector x representing the attempt numbers (1 to 10).
  • Plot your reaction times (v_reaction) against the attempt number (x).
  • Add a horizontal line to the plot representing your average reaction time.
  • Analysis: Look at the plot. Did you get faster, slower, or stay consistent as the 10 attempts progressed? Write a brief comment in your code or a text cell.

Problem 2: Matrix Transformations & Image Representation

Context: In digital image processing, images are often stored as matrices where each number represents a color or intensity. You will manipulate your "Pixel Art" matrix (where values 0-8 represent different colors) to understand how matrix operations affect spatial data.

2.1 Data Initialization

  • Define your 12&times;12 matrix in Python as a NumPy array named M_art.
  • The matrix should contain integers from 0 to 8 (0 represents empty space/background, 1-8 represent different colors/layers).
  • Print the matrix and its shape to confirm it is (12, 12).

2.2 Operation A: The Transpose

  • Create a new matrix M_T which is the transpose of M_art.
  • Print M_T.
  • Concept Check: Does transposing the matrix change the color values (the numbers themselves) or just their positions?

2.3 Operation B: Slicing (Cropping)

  • Create a new matrix M_zoom that consists only of the central 6&times;6 area of your original matrix.
  • Hint: If your matrix is 12&times;12, the center rows are indices 3:9 and columns are 3:9 (slice end is exclusive).
  • Print M_zoom.

2.4 Visual Analysis (Spatial Mapping)

  • Visualize the original matrix M_art using plt.imshow.

    Hint: Use plt.imshow(M_art, cmap='tab10', vmin=0, vmax=9) to clearly distinguish the different numbers as colors.

  • Visualize the transposed matrix M_T in a separate figure.
  • Analysis: Compare the two images. How did the Transpose operation change the orientation of your art? (e.g., Did the image rotate 90 degrees, or did it flip across the diagonal?)

2.5 3D Topography Visualization

  • Use 3D plotting (projection='3d') to create a 3D Bar Chart (Voxel Map) where each pixel value (0-8) determines the height of the bar.

    Logic: Higher numbers (e.g., 8) should result in taller bars, creating a "terrain" or "cityscape" effect. ax.bar3d is a good choice for discrete heights.

  • Analysis: How does mapping the color value to the Z-axis (height) change your perception of the data compared to the flat 2D image?

Problem 3: Maze Solution Plotting

Scenario: You have been given a unique map generated based on your student ID. Your task is to visualize the solution path for a robot to travel from the starting point to the destination.

3.1 Instructions

  • Generate the Map: Go to the Maze tab and enter the last 4 digits of your Student ID to generate the \(15\times15\) maze.
  • Trace the Path: Find a path from Start (green, at \(0,0\)) to End (red, at \(14,14\)). Hover the mouse over the maze to view coordinates. Record the coordinates \((x, y)\) of the turning points (where the robot changes direction).
  • Plot in Python: Plot the maze solution path on a 2D plot and clearly mark the Start and End points; ensure the plot orientation matches the maze.
