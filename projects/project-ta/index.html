Problem 1: Physiological Data Analysis

Context: You are analyzing a dataset representing human reaction speeds. Your goal is to process this vector to determine performance metrics and visualize trends over time.

1.1 Data Initialization

  • Create a NumPy array (vector) named v_reaction containing your 10 reaction time values.
  • Print the array and its shape.

1.2 Statistical Analysis

  • Calculate and print the average (mean) reaction time.
  • Calculate and print the standard deviation (or variance) to see how consistent you were.
  • Note: You may use built-in NumPy functions or write your own logic.

1.3 Performance Thresholding

  • Define a "success" threshold (e.g., any time faster than your average).
  • Create a new list or array containing only the reaction times that met this threshold.
  • Print this filtered list.

1.4 Trend Visualization

  • Generate a time vector x representing the attempt numbers (1 to 10).
  • Plot your reaction times (v_reaction) against the attempt number (x).
  • Add a horizontal line to the plot representing your average reaction time.
  • Analysis: Look at the plot. Did you get faster, slower, or stay consistent as the 10 attempts progressed? Write a brief comment in your code or a text cell.

Problem 2: Matrix Transformations

Context: In Control Systems and Computer Vision, matrices often represent 2D maps or images. You will manipulate your "Pixel Art" matrix to understand how matrix operations affect spatial data.

2.1 Matrix Initialization

  • Define your \(8\times8\) matrix in Python as a NumPy array named M_art.
  • Print the matrix and its shape.

2.2 Operation A: The Transpose

  • Create a new matrix M_T which is the transpose of M_art.
  • Print M_T.

2.3 Operation B: Slicing (Zooming)

  • Create a new matrix M_zoom that consists only of the central \(4\times4\) area of your original matrix.
  • Print M_zoom.

2.4 Visual Analysis (Spatial Mapping)

  • Visualize the original matrix M_art as a 2D image or heatmap.

    Hint: Use plt.imshow(M_art, cmap='Blues') to see the spatial distribution of your 0s and 1s.

  • Visualize the transposed matrix M_T in a separate figure to observe the transformation.
  • Compare the two images.
    Question: How did the Transpose operation change the orientation of your art? (e.g., Did horizontal lines become vertical? Is the image reflected across the diagonal?)

2.5 3D Voxel Visualization

  • Use 3D plotting (projection='3d') to create a 3D Bar Chart (Voxel Map) where each '1' in your matrix is represented by a solid block.

    Hint: ax.bar3d works better than a smooth surface for binary (0/1) data.

  • Analysis: Does this "3D relief" accurately represent the structure of your pixel art? How does the added Z-height help in distinguishing the pattern from the background?
